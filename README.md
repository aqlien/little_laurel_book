# Address Book

This is a simple desktop address book prototype built with Electron.

## Run locally

1. Open a terminal in `d:\Work\gems\address_book`
2. Run `npm install`
3. Run `npm start`

## Build a Windows installer

1. Open a **PowerShell** terminal in `d:\Work\gems\address_book` (do not use WSL unless Wine is installed and configured)
2. Run `npm install`
3. Run `npm run dist`
4. Open the generated installer in `dist\`

After installation, Windows will treat the app like a standard installed program and it will appear in the system's app list.

## Automatic updates

The packaged app supports silent updates from a generic HTTPS update feed. Configure the feed when launching the packaged app with either:

```text
ADDRESS_BOOK_UPDATE_URL=https://example.com/address-book-updates/
```

or:

```text
Address Book.exe --update-host=https://example.com/address-book-updates/
```

Leave the host unset during development or until the update server is ready. The feed must serve the files generated by `npm run dist`, including the installer and `latest.yml`. Downloaded updates are installed automatically when the app next quits and restarts.

## Data storage

Contacts are stored in a SQLite database named `address-book.sqlite` in Electron's per-user application data directory. On Windows, the default path is usually `C:\Users\<username>\AppData\Roaming\address-book\address-book.sqlite`. The database is created automatically when the app starts. Back up the database file while the app is closed.

The data directory can be changed with the `ADDRESS_BOOK_DATA_DIR` environment variable or the `--data-dir=` command-line option. The command-line option takes precedence:

```text
ADDRESS_BOOK_DATA_DIR=D:\Address Book Data
Address Book.exe --data-dir=D:\Address Book Data
```

The configured path is resolved as an absolute path, and the directory is created automatically when the app starts.

## Build and publish a release

After installing and authenticating the GitHub CLI (`gh auth login`) in PowerShell, run:

```text
npm run release
```

This builds the Windows installer, creates the `latest` GitHub release the first time, and uploads or replaces the installer, blockmap, and `latest.yml` assets on later runs. Update the version in `package.json` before each release.

## Files

- `index.html` — app HTML
- `css/main.css` — app styles
- `js/main.js` — app logic
- `electron-main.js` — Electron main process
- `preload.js` — preload script
- `address-book.sqlite` — runtime SQLite database in the per-user application data directory
- `package.json` — Electron startup settings and build config
